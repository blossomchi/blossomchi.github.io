# Chinyere Blossom Oyem — personal research site

Static site for GitHub Pages (https://blossomchi.github.io/). No build step: edit the HTML files directly.

- `index.html` — home page (research, publications, builds, teaching, background, credentials, contact)
- `project4.html` gesture-controlled assistive arm (CDAM-Net) · `project5.html` firefighting robot · `project7.html` search-and-rescue planner
- `project1.html`, `project2.html`, `project3.html`, `project6.html` — earlier builds and teaching materials
- `style.css`, `site.js`, `fonts/`, `img/`

To change a paper's status or venue, edit the "Publications" block in `index.html` and the status line at the top of the matching project page.
